# Ask Fiona — which one should I wear?

New Glamour Suite card (below fit-check):
- **Take a Photo** or **Upload** pieces/outfits (and a selfie if available)
- Optional note (occasion / “black vs blue”)
- **Ask Fiona ✨** → decisive pick grounded in her photos

API: `POST /api/fiona/glamour/style` with `mode: "ask"`  
Returns `pick`, `why`, `skip`, `howToStyle`, `compliment`, `wingwomanQuip`.
