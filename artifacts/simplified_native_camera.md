# Simplified camera capture

## Take a Photo (native)
- Uses `<input id="camera-input" type="file" accept="image/*" capture="user">`
- Opens the phone/tablet’s own camera (timers, lenses, hardware) — **no in-app frame**

## Live Camera (optional in-app)
- Full-bleed video only — no box frames / silhouettes / guide overlays
- Front camera by default + **Flip**
- **3s Off/On** toggle next to shutter → large 3…2…1 then snap
- Shutter feedback: short beep + haptic when supported
- Review: **Retake** or **Use Photo ✨** → Canvas / Glamour pipeline

PWA shell/cache: **v23**
