HOW TO UPLOAD

1) Put these 3 files into GitHub folder: api/fiona/
   - checkout.js
   - stripe-config.js
   - session.js

   (That is the same folder that already has "glamour")

2) Put these 3 files into the main repo folder (next to your current index.html):
   - index.html
   - pricing.html
   - dashboard.html

3) Commit changes and wait for Vercel.
